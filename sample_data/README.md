# Sample Data Directory

This directory contains test and sample financial documents for the Document Intelligence System.

## Supported Document Formats
- **PDF**: Single and multi-page invoices / financial reports (tested up to ~1,000 pages).
- **Images**: `JPG`, `PNG`, `TIFF` scanned receipts, bills, and purchase orders.
- **Spreadsheets**: `XLS`, `XLSX`, and `CSV` structured tabular financial statements and ledger extracts.

Sample financial documents will be populated here for validation in subsequent phases.
